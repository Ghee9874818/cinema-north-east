# Data status

Official Alnwick Playhouse, Tyneside Cinema and Everyman Newcastle programmes refresh daily at 08:17 Europe/London. GitHub may delay a scheduled run; collection timestamps, coverage and current status are recorded per venue in screenings.json. Listings are programme records, not live seat availability.

Each run validates fresh data, preserves last-good rows on source failure, publishes honest unavailable/stale status, and verifies the public files after deployment. A failed source is reported as a failed workflow after safe publication of retained data.

Vue Cramlington returned HTTP 403 from GitHub Actions. Cineworld Newcastle and both ODEON venues also have no validated automated feed. All four remain visible with official programme links; cached development fixtures are never published.
